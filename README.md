# Cybersecurity Threat Intelligence Dashboard (Power BI)

## Project Overview

An interactive cybersecurity dashboard built using Microsoft Power BI to analyse network activity, attack patterns, severity levels, traffic types, and security actions.

## Dashboard Features

### Interactive Slicers
- Attack Type
- Severity Level
- Traffic Type
- Protocol
- Action Taken
- Network Segment

### Key Performance Indicators
- Total Network Events
- Total Attack Types
- Unique Source IPs
- High Severity Events
- Average Packet Length
- Malware Detected

### Visualisations
- Average Packet Length by Attack Type
- Severity Distribution
- Network Traffic by Type
- Attack Trends Over Time
- Security Actions Taken
- Average Anomaly Score by Attack Type

## Tools and Technologies
- Microsoft Power BI
- Power Query
- DAX

## Dataset

Cyber Security Attacks dataset by Team Incribo.

[Kaggle Dataset](https://www.kaggle.com/datasets/teamincribo/cyber-security-attacks)

The dataset contains 40,000 network-event records.

## Project Objective

To explore cybersecurity event data, identify attack patterns, analyse severity distribution, and present useful insights through an interactive dashboard.

## Disclaimer

This is a learning and portfolio project. It is not a live cybersecurity monitoring system.
